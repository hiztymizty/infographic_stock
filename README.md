# Hakabot Video Studio

Short vertical infographic videos about the Indonesian stock market, made with code-driven motion
graphics (Remotion), an ElevenLabs Bahasa voiceover and synthesized sound effects. Every video
carries the Hakabot watermark and outro.

**Start here:** open this folder in Claude Code and say what you want ("cari ide topik baru",
"lanjutkan ep01"). The main agent works as the producer and runs a team of subagents
(`.claude/agents/`). The whole workflow, rules and commands are in [CLAUDE.md](CLAUDE.md). What's in
progress, and the next step, is in `episodes/<id>/status.md`.

## Setting up a new PC

1. **Install**
   - Node.js 22 or newer (developed on 26).
   - Python 3.12+ with `numpy`, `scipy`, `Pillow` and `xlrd` (`python -m pip install numpy scipy pillow xlrd`; xlrd reads BI's .xls tables).
   - Git and **Git LFS** (the raw outro recordings in `outro_raw/*.mp4` are stored with LFS; run `git lfs install`
     once, then `git lfs pull` if a clone shows tiny pointer files instead of videos).
2. **Project dependencies:** `npm install`. The first render downloads Chrome Headless Shell (~120 MB) automatically.
3. **Secrets:** `cp .env.example .env`, then fill it in. `.env` is git-ignored; never commit it.
   - `ELEVENLABS_API_KEY`: needs a **paid** ElevenLabs plan. The free plan can't use library voices through
     the API, and it has no commercial license.
   - `ELEVENLABS_VOICE_ID`: the narrator. The current one is **Pratama** (`q8qwd1jY2jS3AWOBeq25`, an Indonesian
     male library voice). On a new ElevenLabs account, add it first with
     `python -I scripts/voices.py --add q8qwd1jY2jS3AWOBeq25`.
   - `ELEVENLABS_MODEL_ID=eleven_v3`: the user chose v3 over multilingual_v2 by ear.
4. **Windows only:** turn off **Smart App Control** (Windows Security → App & browser control). It blocks
   Remotion's bundled `ffmpeg.exe`, which stops both voice mastering and video renders. The tools check for
   this and stop before spending anything. See CLAUDE.md → Gotchas.
5. **Check it works:**
   - `npm run typecheck`
   - `npx remotion ffmpeg -hide_banner -version` should print a version line.
   - `npm run render -- ep01-ihsg-dca --stills 0`

Renders use a lot of memory, so close other heavy apps. `RENDER_CONCURRENCY=2 npm run render -- <id>` is
gentler on a 16 GB machine.

## What's in git, and what isn't

- **In git:**
  - source code, docs and agents
  - episode data, scripts, facts and status
  - mastered voice takes (`public/episodes/*/vo/`) and their raw sources (`episodes/*/vo-raw/`), so nothing
    needs re-billing on another PC
  - brand assets and the outro clips
  - the raw outro screen recordings (`outro_raw/`; the `.mp4` files via Git LFS, one is over GitHub's 100 MB limit)
- **Not in git** (regenerated by the commands in CLAUDE.md): `node_modules/`, `.env`, rendered videos
  (`episodes/*/out/*.mp4`), QA stills and previews, root `out/`, and the archived English cut's videos.
- **Privacy:** `outro_raw/` and `public/outro/` contain the unblurred app recordings (account name, browser
  tabs, tickers); the blur is applied at render time. Keep this repository **private**.

## Pending requests from the user

- A **female narrator** option ("later I want to also do woman voice, make sure to find me one later").
  Find candidates with `python -I scripts/voices.py --library female` (free preview mp3s in `out/voice-previews/`),
  let the user pick by ear, then use `voice.voiceId` in an episode's `script.json` (or `ELEVENLABS_VOICE_ID`).
- **Music:** each episode gets an original synthesized score (`npm run music -- <id>`, see the style guide). The user may
  still supply licensed tracks into `public/music/` later; don't download music yourself.
